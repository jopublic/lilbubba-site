🔧 Installing K8 — three steps
  1. Open the file you just downloaded.
  2. Windows shows a blue “Windows protected your PC” box. Click More info, then Run anyway.
  3. Paste one of your reviewer keys the first time K8 opens.

⚠️ The blue box is not a virus warning — it's just Windows saying it doesn't recognise an app from a small independent developer yet. That box goes on how well-known a file is, not on what's inside it. However, K8 is published in Microsoft's own Windows Package Manager — reviewed and listed by Microsoft — so you can install it with the command below instead if you'd rather.
